# SD-103 · Checkout

As a shopper I want to check out my cart so that I can complete my order.

## Acceptance criteria
- AC1: From the cart, "Checkout" opens "Checkout: Your Information".
- AC2: First name, last name and postal code are all required; each missing field shows its own error
  ("Error: First Name is required", "Error: Last Name is required", "Error: Postal Code is required").
- AC3: The overview lists every product in the cart with its price.
- AC4: Item total = sum of item prices; Tax = 8% of item total (rounded to cents); Total = Item total + Tax.
- AC5: "Finish" shows "Thank you for your order!" and empties the cart.
