# SD-102 · Cart

As a shopper I want to collect products in a cart so that I can buy them together.

## Acceptance criteria
- AC1: Clicking "Add to cart" increments the cart badge and the button changes to "Remove".
- AC2: Removing a product from the cart page removes it from the list and updates the badge.
- AC3: Cart contents persist while navigating between inventory and cart.
