# SD-101 · Login

As a shopper I want to log in so that I can see the product catalogue.

## Acceptance criteria
- AC1: A valid user lands on the "Products" page after login.
- AC2: A locked-out user sees "Epic sadface: Sorry, this user has been locked out." and stays on the login page.
- AC3: Wrong or missing credentials show a specific validation error (username required / password required / no match).
- AC4: A logged-in user can log out from the burger menu and returns to the login form.
