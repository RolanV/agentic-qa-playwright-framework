# BK-201 · Booking CRUD

## Acceptance criteria
- AC1: POST /booking returns 200 with a bookingid and echoes the booking.
- AC2: GET /booking/{id} returns the stored booking.
- AC3: PUT/PATCH/DELETE without a token return 403.
- AC4: PATCH changes only the supplied fields.
- AC5: After DELETE, GET returns 404.
- AC6: GET /booking returns a list of { bookingid } objects.
