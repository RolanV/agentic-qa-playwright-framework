# SD-104 · Product sorting

As a shopper I want to sort the product list so that I can find what I want faster.

## Acceptance criteria
- AC1: The sort dropdown offers: Name (A to Z), Name (Z to A), Price (low to high), Price (high to low).
- AC2: Default order is Name (A to Z).
- AC3: Choosing an option re-orders the list immediately, without a page reload.
- AC4: Price sorting is numeric (e.g. $7.99 comes before $15.99).
- AC5: The chosen sort does not change the cart contents.
